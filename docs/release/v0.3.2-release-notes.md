## 支援範圍

### SUPPORTED

v0.3.2 延續 v0.3.1 已發布且已有 evidence 的產品邊界，並只加入 bounded correctness / Retrieval Inspector / Browser UX corrective：

- upload → READY_TO_USE → grounded Ask / citation。
- Ask 保存成 Proposal → Human Review → Approve → Draft / Preview → explicit Publish。
- Published Wiki read 與既有 workspace-scoped canonical authority。
- 持久化 failure diagnostic redaction 收斂。
- Grounded Ask 在 Answer Provider consumption boundary 前重新驗證 final EvidenceBundle currentness。
- Retrieval Inspector 以白話區分原問題、另一種問法與最後可用來源。
- Ask → Retrieval Inspector handoff 保留實際 retrieval mode 與 selected-document scope。
- 引用來源定位可把 viewport / keyboard focus 帶到正確 preview，切換至 Inspector 時不殘留重複來源面板。
- Human Review 與 explicit Publish gate 維持不變。

### CANDIDATE／選擇性能力

下列能力維持既有 readiness / degradation contract，不因 v0.3.2 發布升格為新的預設承諾：

- semantic / vector retrieval。
- Graph projection / traversal / graph-enhanced retrieval。
- optional provider-backed query transformation；既有 default 不因本 patch 改變。

Graph 仍是 derived、provider-neutral projection，不成為 canonical authority。

### NOT SUPPORTED／DEFERRED

v0.3.2 明確不新增或升格：

- OCR／layout provider。
- MCP write／agent write。
- auto-approve／auto-publish。
- 新 Answer / Embedding / Query Rewrite provider。
- 新 retrieval ranking default 或未經獨立 Issue / evidence 驗證的 query transformation default。
- Graph authority。
- raw public backend exposure。
- 未驗證的效能／SLA 保證。

## Patch 摘要

### 1. 持久化 diagnostic redaction

Refs #666

- durable failure diagnostic 進一步收斂敏感值、路徑與不必要內部細節。
- operator-facing 診斷仍保留足以排查問題的 bounded information。
- 不以 raw secret、raw request body、credential 或本機敏感路徑作 observability 交換。

### 2. Retrieval Inspector summary scope 與白話 UX

Refs #667 #673

- 明確標示「你原本問的問題（原始查詢）」。
- 將「系統為了找資料而嘗試的另一種問法（改寫查詢）」與 original-query summary 分離。
- 將「最後可用來支持回答的來源（最終證據）」與 query attempts 清楚區分。
- 沒有採用另一種問法時明確顯示未發生，不要求使用者理解 retrieval pipeline 術語。

### 3. Answer Provider consumption-window currentness

Refs #670

- 在 Answer Provider handoff 前重新驗證 final EvidenceBundle currentness。
- stale / missing / ineligible evidence fail closed。
- 不以 provider response、Graph row、vendor score 或先前曾有效的 snapshot 取代 canonical authority。
- 不改 retrieval ranking / backfill policy。

### 4. 引用定位與 Inspector scope handoff

Refs #673 #675

- 「檢視來源位置」會把畫面帶到可見的「引用來源預覽」，並保留鍵盤焦點。
- Ask 成功後保存實際使用的 question / retrieval mode / optional selected document id。
- 進入 Retrieval Inspector 時沿用同一 retrieval mode 與 selected-document scope，不再用不同檢索範圍重新查詢。
- `/api/v1/retrieval/inspect` 的 optional `documentId` 仍受 active workspace、freshness 與 authority revalidation 約束。
- 離開 Ask route 時清除舊 inline preview，避免和 Inspector 的「來源片段檢視」重複出現。
