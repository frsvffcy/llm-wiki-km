## Patch 摘要

v0.3.1 不新增產品功能。相對 v0.3.0，production scope 收斂為 correctness / governance patch 加上一個小型 Browser 顯示修正。

### 1. ASK Proposal durable evidence currentness

Refs #649 #651

Ask 保存成 Proposal 後，後續治理流程不再只相信「當初曾經有效」的 citation：

- ASK evidence 使用 versioned durable snapshot。
- WIKI citation 持久化 validated revision 與 canonical knowledge identity。
- duplicate save 在回傳既有 Proposal 前會重新驗證 evidence。
- REVIEW → APPROVED 前重新驗證 evidence currentness。
- auto/manual/regenerate draft 建立時再次 fail closed。
- legacy / malformed ASK snapshot 不發明 revision，維持 fail-closed。
- SOURCE workspace/status/parse/chunk authority 與 WIKI revision/content authority drift 都有 deterministic integration coverage。

### 2. Publish commit-point TOCTOU corrective

Refs #652 #653

關閉 publish preflight validation 與 canonical commit 之間的 consumption-window race：

- CREATE / MERGE finalizer 在 canonical metadata commit 前使用共用 commit-point guard。
- finalizer transaction 的第一個 DB statement 先取得 SQLite writer serialization，再重讀 fresh draft / proposal / persisted ASK evidence。
- stale evidence 沿用 stable `WIKI_PUBLISH_PROPOSAL_INVALID`，不得默默完成 publish。
- file 已 stage/commit 後才發現 stale 時，沿用 deterministic filesystem compensation / ledger safe-state。
- app-owned Wiki publish 以 persistent per-workspace lock 序列化，不使用不安全的 lock handoff remove lifecycle。
- deterministic concurrency tests 覆蓋 SOURCE/WIKI drift、CREATE/MERGE parity、2-thread attempt barrier 與 3-thread lock handoff；不以 sleep/retry luck 當 correctness evidence。

### 3. Wiki 清單 pager 文案修正

Refs #650 #654

- Wiki 知識清單將 `totalElements` 正確顯示為「共 N 筆」，不再誤標為「共 N 頁」。
- regression fixture 明確使用 `totalElements != totalPages`，並同時鎖定 prev / next button state。
- 不變更 API、page size、filter 或 pagination authority。

- 不改 retrieval ranking / query transformation / prompt default。
- 不新增 provider。
- 不改 Graph authority / vector capability policy。
- 不新增 Flyway schema migration。
- v0.3.0 tag / Release / assets 不重建、不覆寫、不 retag。

## Release Candidate 必要驗收

Refs #655

正式給出 `READY_TO_PUBLISH` 前，必須以 exact packaged candidate 完成既有 `.github/workflows/release-candidate.yml`：

- reproducible build twice / bit-identical SHA-256；
- Maven / runtime / manifest / artifact identity 一致；
- clean-install smoke；
- backup → fresh-root restore → restart smoke；
- Browser first-mile packaged gate；
- sqlite-vec JDBC smoke；
- product acceptance；
- readiness gate 明確輸出 `READY_TO_PUBLISH` 或 `NO-GO`，不得 fake-green。

另需 packaged human checkpoint：

- upload → READY_TO_USE；
- grounded Ask + citation；
- 保存成知識 → Review → Approve → draft / preview；
- explicit Publish → Published Wiki read；
- 肉眼確認 Wiki pager 顯示「共 N 筆」；
- 不以人工 timing 嘗試重現 concurrency race；該 correctness 以 deterministic executable tests 為 authority。
