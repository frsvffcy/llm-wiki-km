# v0.3.1 候選發布說明

> 本文件是 v0.3.0 正式發布後的 current-main development placeholder。
> Executable API／schema authority 仍是 runtime contracts、Flyway、ADR 與 tests；本文件不預先承諾下一版 release scope。

## 發布狀態

- 發布狀態：CANDIDATE
- 候選版本：`0.3.1`（Maven `pom.xml` 為版本唯一權威）
- 已發布基準：`v0.3.0`；其 annotated tag、GitHub Release 與 11 個公開 assets 保持不可變。
- `v0.3.1` 目前只是 post-release 開發識別，尚未建立 exact candidate、tag、GitHub Release 或公開 assets。

## 範圍原則

- 不因版本號存在就預設一定發布 `v0.3.1`。
- 新功能仍須由實際 trigger／Issue／驗收證據決定，不自動把 deferred candidate 升格為 roadmap。
- 若未來形成 release candidate，仍須重新完成 production delta inventory、exact artifact identity、automated acceptance 與 packaged human checkpoint。
- `READY_TO_PUBLISH` 仍不等於 publication authorization；公開 tag／Release／assets 需要新的 A2 人類明確授權。
