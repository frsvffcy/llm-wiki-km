## SUPPORTED

- LOCAL_ONLY（`server.address=127.0.0.1`，owner auth 可開可關；provider / backend disabled 不拖垮 baseline）。
- PRIVATE_INGRESS Mode 1（依 #422 / #423 hardened contract：canonical browser origin 四方對齊、
  versioned salted adaptive KDF verifier、bounded forwarder、raw backend loopback-only、
  wrong Host / Origin / transport fail closed）。
- Ingestion / extraction（含 bounded extraction ceilings、versioned chunking / normalization policies、
  Tika structured parse、CJK bigram lexical projection）。
- Retrieval：FTS lexical、embedding projection lifecycle、vector KNN（需 sqlite-vec prerequisite）、
  hybrid fusion、second-stage exact-anchor rerank（default）、Evidence assembly、Retrieval Inspector、
  Source Chunk locator。
- Ask：stateless grounded answer（`grounded-answer@v2`）、citation validation、provider egress
  transparency（configuration + execution disclosure）、typed provider-disabled / retrieval failures。
- Governance：Ask → Proposal（explicit mutation command、citation currentness、per-workspace dedup）、
  Proposal → Draft → Human Review → explicit Publish、Published Wiki read（PUBLISHED-only、content hash）、
  Vault Lint read-only triage、governed repair ingress（`CANONICAL_CONTENT_INVALID` eligible only）。
- MCP read-only loopback adapter（五個唯讀 tools，bounded transport-error envelope，無 write tools）。
- Operations：single-instance JAR + systemd primary、container mechanism（約束見 #418）、WAL-safe
  backup / restore operator procedures、deployment readiness projection、diagnostic redaction boundary。

## CANDIDATE / DISABLED BY DEFAULT

- Public HTTPS Mode 2（`REVERSE_PROXY_CANDIDATE`；contract 明確但永不回 SUPPORTED，需未來 adoption）。
- Query transformation single-rewrite（evaluation CONDITIONAL GO；production default 仍 disabled，
  需 versioned policy + exact-token protection + 另開 adoption issue）。
- Optional Graph projection（需 `GRAPH_PROJECTION_ENABLED` + ArcadeDB embedded prerequisite +
  readiness READY；unavailable 時 lexical + vector baseline + typed degradation）。
- Optional vector / semantic（需 `VECTOR_CAPABILITY_ENABLED` + pinned sqlite-vec native +
  embedding provider + projection READY；缺失為 typed unavailable，不破壞 baseline）。
- Container packaging（mechanism，有 single-instance / host-network / non-root 約束；primary 仍為 JAR + systemd）。

## NOT SUPPORTED / DEFER

- Direct raw Internet bind（`0.0.0.0` / wildcard；validator fail-fast，REJECT）。
- OCR / scanned-PDF / layout-aware ingestion。
- MCP / agent write、autonomous publish / repair、auto-fix。
- Multi-user / RBAC / tenant、HA / multi-instance、PostgreSQL / Kubernetes。
- Maven Central / package registry publication、code-signing / notarization、native installer（DMG / MSI）、
  Docker registry image publication。
- Performance / SLA certification、live-provider quality / SLA guarantee。
- Query transformation default enablement、EXTRACTIVE compaction promotion、新 retrieval mode / ranking policy、
  claim-level contradiction ledger。
