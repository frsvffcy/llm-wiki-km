## 支援範圍

### SUPPORTED

目前只延續 v0.3.2 已發布且已有 evidence 的產品邊界；本 placeholder 不新增或升格任何能力。

### CANDIDATE

- `v0.3.3` 只是 mutable main 的開發識別，不代表一定會形成正式 Release。
- 下一個 feature / corrective / Sprint 必須由實際 trigger、Issue、code audit 與驗收證據決定。
- 若未來形成 release candidate，仍須重新完成 production delta inventory、exact artifact identity、automated acceptance 與 packaged human checkpoint。
- `READY_TO_PUBLISH` 仍不等於 publication authorization；公開 tag／Release／assets 需要新的 A2 人類明確授權。

### NOT SUPPORTED

此 placeholder 不承諾或升格：

- retrieval / ranking / query transformation default 變更；
- OCR / layout provider；
- MCP / agent write；
- auto-approve / auto-publish；
- 新 provider；
- Graph authority；
- public backend exposure；
- 尚未有獨立 Issue 與 evidence 的任何功能。
