## 候選範圍

### 1. 使用者可見：first-use 工作導向 Browser UX（#680）

Post-v0.3.2 的兩個獨立真人 session 重複確認 first-use discoverability gap，#680 因此將 Browser 首頁／導覽收斂為：

- 有 active workspace 時，首頁直接突出「閱讀 / 管理文件」；
- workspace 管理、提問、待我審核、檢視器、品質等進階入口採漸進揭露；
- 沒有 workspace 時直接突出建立工作區；
- deep links、REST API、workspace/currentness/citation/publish authority 不變；
- 不新增 wizard state、backend API 或 schema。

Merged main 上 owner Browser checkpoint 為 **5/5 PASS**；PR CI、Main Merge Guard、Full Regression Canary 均成功。

### 2. 使用者可見：Grounded Answer 多證據引用完整性（#682 / #685）

#682 建立 opt-in、test-only 的真實 Answer Provider measurement。最初 `grounded-answer@v3` 在 `CONFLICTING_INFO` 兩次量測中有一次只引用 1/2 required evidence，因此觸發 #685。

#685 將 prompt contract 升為 `grounded-answer@v4`，明確要求：

- material conflict 必須引用所有相關衝突來源；
- 完整回答需要多份證據時，引用每一份有實質貢獻的來源；
- 不得為了提高 citation coverage 引用無關 evidence。

Owner-controlled real-provider rerun：

```text
CONFLICTING_INFO       3/3 COMPLETE, required recall = 1.0
COMPLETENESS_REQUIRED  3/3 COMPLETE, required recall = 1.0
false abstention       0/6
decision               NO_CHANGE
```

這只證明目前 bounded synthetic live-provider cases 不再重現 v3 的缺口；**不代表所有模型、私人 corpus 或所有問題都有 universal quality / SLA 保證**。

### 3. Evaluation / tooling：不算新 runtime feature

- **#682 live-provider harness**：新增 opt-in `live-provider` profile 與 privacy-safe measurement；normal fast/integration/full 不執行 provider network measurement。PR Build Integrity 只做 no-network compile。
- **#689 Graph relation-loss sensitivity**：deterministic fault-injection 證明 Graph discovery value 對 projection completeness 敏感；FTS/vector baseline exact-retained。Decision = `KEEP_GRAPH_OPTIONAL_AND_MEASURE_PROJECTION_COMPLETENESS`。不修改 production Graph relation admission、fusion weight、retrieval default。
- 2026-10-06 evaluation batch / lineage cleanup（#687 / #690 / #695）只屬 evaluation / governance evidence，不形成新的 runtime backlog。

### 4. 文件：local OpenAI-compatible / Ollama 使用指南（#688）

新增繁中本機 Provider recipe，說明如何把既有 OpenAI-compatible Answer（以及可選 Embedding）指向 loopback provider，例如 Ollama。

這是**既有能力的設定文件**：
- 不新增 Ollama runtime dependency；
- 不把本機 provider 設成 default；
- 不修改 provider adapter；
- 不建立 Browser key 設定頁；
- 不宣稱特定模型有固定繁中品質或 SLA。
